# CrossGrowth Demo Guide

## Demo Goal

Show a **claim-safe ecommerce creative copilot prototype**. The demo should emphasize how CrossGrowth turns review evidence into a bounded creative workflow while keeping real execution disabled.

## Demo Line

```text
review evidence -> claim safety -> creative output -> delivery QA -> final export -> dossier -> readiness
```

Recommended walkthrough:

- Start with review evidence and evidence quality.
- Show claim-safety boundaries and unsupported-claim handling.
- Show claim-safe creative output and delivery QA previews.
- Show remediation and verification previews.
- Show final export packet, campaign dossier, and MVP readiness dossier.
- Close on the safety boundary and post-MVP unlock plan.

## Required Framing

- This is a deterministic preview.
- There is no real LLM call.
- There is no provider call.
- There is no real media upload, download, or storage.
- There is no real file export.
- There is no platform upload or publishing.
- There is no real legal or compliance conclusion.
- There is no database persistence or real customer-data processing.

## Do Not Present As

- a real customer case study
- a real platform approval result
- a real ad that has been generated or published
- a real provider integration
- real buyer evidence beyond the deterministic demo inputs
- legal advice or a platform compliance certification
