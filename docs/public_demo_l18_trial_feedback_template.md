# L18 Trial Feedback Template

Status: ready

Commit: c3050a4

## 每个试用者只记录 5 项

### 1. 选择了哪个入口？

- 我有产品想法
- 我有用户评论/反馈
- 我先看示例

### 2. 有没有成功生成？

- 成功
- 失败
- 中途放弃

### 3. 卡在哪里？

记录原话即可。

例如：

- 不知道该点哪个按钮
- 不知道产品描述怎么写
- 不理解用户痛点
- 结果太长
- 结果看起来有用
- 还是有英文看不懂

### 4. 哪个区块最不清楚？

可选：

- 首屏
- 三个路径卡片
- 产品想法输入区
- 用户反馈输入区
- 生成结果
- 最近生成记录
- 反馈 / 试用名单

### 5. 他/她觉得这个工具有没有用？

记录一句原话。

## 推荐记录格式

| 试用者 | 入口 | 是否生成成功 | 卡点 | 最不清楚区块 | 是否觉得有用 | 原话 |
|---|---|---|---|---|---|---|
| friend_1 | 我有产品想法 | 是 | 暂无 | 结果区 | 有 |  |
| friend_2 | 我先看示例 | 是 | 不知道示例是什么 | 示例区 | 不确定 |  |
| friend_3 | 我有用户评论/反馈 | 否 | 没有真实评论 | 输入区 | 不确定 |  |

## 记录规则

不要解释太多。

只记录真实反应。

如果朋友通过微信反馈，直接把关键原话复制进表格即可。
