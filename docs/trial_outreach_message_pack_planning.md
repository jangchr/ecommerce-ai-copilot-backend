状态：ready

## 当前 commit

## 目标

准备真实用户试用邀请文案。

当前 Public Demo 已具备：

- 快速试用入口
- Product Description Mode
- Pasted Reviews Mode
- English / 中文
- Feedback CTA
- Waitlist CTA
- Result follow-up CTA

现在需要把 demo 发给真实用户，收集反馈。

## 目标用户

优先顺序：

1. 中文电商卖家
2. 英文电商卖家
3. TikTok Shop seller
4. Shopify seller
5. UGC creator
6. TikTok ad freelancer
7. small creative agency

## 文案类型

需要准备：

- 中文短私信
- 中文详细私信
- 英文短私信
- 英文详细私信
- 面向 creator 的版本
- 面向 ecommerce seller 的版本
- follow-up 消息
- feedback reminder 消息

## 核心 CTA

希望对方做三件事：

1. 打开 Public Demo
2. 试一次 Product Description 或 Pasted Reviews
3. 提交 Feedback 或加入 Waitlist

## 发送原则

文案要短。

不要过度解释技术。

不要说还在开发很多复杂功能。

重点说：

- 不需要登录
- 可以用示例产品
- 可以粘贴自己的产品描述或评论
- 想听听对方是否觉得有用

## 不做

- 不群发 spam
- 不承诺付费功能
- 不承诺 Amazon URL 已支持
- 不夸大生成质量
- 不说已经适合大规模商业使用
