## 执行顺序

1. 先发给最可能愿意帮忙的人
2. 不解释太多技术
3. 只让对方完成一次最短路径
4. 试完后问 1 到 2 个问题
5. 记录是否提交 feedback / waitlist

## 最短试用路径

中文：

1. 打开 demo
2. 点击快速试用
3. 用示例产品或示例评论
4. 点击生成
5. 看 Hook / 分镜
6. 点提交反馈或加入 waitlist

English:

1. Open demo
2. Use quick start
3. Try sample product or sample reviews
4. Generate once
5. Check hook / storyboard
6. Give feedback or join waitlist

## 第一轮判断标准

如果 5 人里至少 2 人觉得有用：

继续第二轮 5 人。

如果多数人看不懂：

回到 public demo copy polish。

如果多数人要求 URL input：

重新评估 Shopify / Amazon input source。

如果没人愿意打开：

优化 outreach 文案和目标用户选择。

## 结论

可以开始第一轮 5 人试用。
