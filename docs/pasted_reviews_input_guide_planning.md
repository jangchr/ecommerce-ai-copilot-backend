# L14.5-B Pasted Reviews Input Guide Planning

状态：ready

## 目标

规划 Pasted Reviews Mode 的输入指南。

## 用户问题

用户可能不知道应该粘贴什么：

- Amazon review
- TikTok comment
- Reddit comment
- 客服反馈
- 买家抱怨
- 差评
- 购买顾虑
- 竞品评论

## 推荐页面提示

English:

Paste reviews, complaints, objections, or buyer feedback. More specific comments create better hooks and storyboards.

中文：

粘贴评论、差评、购买顾虑或买家反馈。评论越具体，生成的 Hook 和分镜越贴近真实痛点。

## 好输入包含

- 用户原话
- 重复出现的痛点
- 购买前顾虑
- 使用后的不满
- 用户希望更方便的地方
- 竞品差评
- TikTok 评论

## 差输入示例

- good product
- nice
- works well
- no complaints
- buy now

## 好输入示例

- I hate cleaning my big blender every morning.
- It is too loud for my apartment.
- I only need one smoothie, not a huge blender jar.
- I skip protein shakes because cleanup takes too long.

## 结论

下一步前端可增加 paste guide 和 good / bad examples。
