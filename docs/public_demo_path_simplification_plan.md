# L15.0-D Public Demo Path Simplification Plan

状态：ready

## 当前 commit

d35bf1e

## 目标

减少新用户第一次试用路径中的选择成本。

## 推荐主路径

最短路径：

1. 打开 demo
2. 选择语言
3. 点击 Use sample product 或 Use sample reviews
4. 点击 Generate
5. 查看 Hook / Storyboard
6. 点击 Feedback 或 Waitlist

## 当前可简化点

- 强化 Use sample product
- 强化 Use sample reviews
- 弱化不必要的说明
- Debug section 放更后
- Feedback / Waitlist 更靠近结果区域
- 让用户知道“不需要登录”

## Product Description Mode 路径

推荐文案：

Use this if you can describe the product yourself.

中文：

如果你能自己描述产品，用这个模式。

## Pasted Reviews Mode 路径

推荐文案：

Use this if you have reviews, complaints, or buyer feedback.

中文：

如果你有评论、差评或买家反馈，用这个模式。

## 不做

- 不删除任何现有能力
- 不改 endpoint
- 不改后端
- 不改 Debug Mode 逻辑
- 不新增 tracking script

## 结论

Public Demo 要让用户“一眼知道先点哪里”。
