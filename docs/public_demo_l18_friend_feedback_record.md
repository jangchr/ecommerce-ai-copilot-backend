# L18 Friend Feedback Record

Status: recorded

Commit: 24b468f

## 反馈来源

来自中文朋友试用前后的人工反馈整理。

反馈主要通过微信沟通，不依赖表单。

## 已收到的核心反馈

### 1. 中文体验必须完整

中文模式下不能只翻译大标题。

需要中文化：

- 小按钮
- 输入引导
- placeholder
- 最近生成记录
- 反馈入口
- 结果区提示
- 数据来源说明

原因：

中文用户如果看到英文残留，会降低理解成本和信任感。

### 2. 示例产品 / dataset 概念容易让普通用户困惑

朋友不理解 dataset 是什么。

Public Demo 里应避免让普通用户理解：

- dataset
- slug
- source_type
- debug
- Amazon Shadow
- telemetry

这些可以保留在技术路径里，但不应出现在主体验。

### 3. 非电商用户需要“动动手指就能开始”的路径

对非电商用户来说，吸引点不是“我是电商卖家”，而是：

> 我只要有一个产品想法，系统能不能引导我 10 分钟内生成一个可以尝试上架 / 发短视频的产品表达？

因此 L18 需要强调：

- 我有产品想法
- 我有用户评论/反馈
- 我先看示例
- 不需要先懂电商
- 不需要先懂数据集

### 4. 原页面流程不够清晰

用户会不知道从哪里下手。

之前的问题包括：

- 输入框太多
- 区块堆叠
- 生成后要滑到底部找结果
- 产品想法路径和用户评论路径混在一起
- 反馈 / waitlist 区域重复

L18 已用 active workspace 和 inline result panel 解决主要问题。

### 5. 有经验电商用户暂时不能代表

当前反馈主要来自非电商或普通中文用户。

对有经验电商卖家的工作习惯，现在还没有足够样本。

后续不能假设他们会喜欢当前流程，需要真实访谈。

### 6. 未来可以考虑聊天式需求收集

朋友反馈里提到：

可以考虑接一个大语言模型 API，让用户通过聊天方式说出自己的需求。

这个方向暂时记录，不立即做。

原因：

- 会增加产品复杂度
- 可能引入新 API 成本
- 当前阶段更需要先验证静态流程是否能让用户完成一次生成

## L18 已响应的改动

- 三路径入口
- 中文主路径本地化
- 输入引导中文化
- 最近生成记录中文化
- 结果就地展示
- 隐藏 Target platform / Goal
- 底部反馈入口去重
- 技术概念从主路径降级

## 暂不继续做的事项

- 不立即接聊天 API
- 不立即做登录
- 不立即做支付
- 不立即继续大规模前端重构
- 不再为没有真实反馈的问题继续 polish

## 下一步

拿 L18 final 给朋友继续试用。

重点观察：

1. 是否知道该点哪个入口
2. 是否能在 1 分钟内开始填写
3. 是否能理解生成结果
4. 是否知道下一步可以复制 / 修改 / 反馈
5. 是否还有中文残留英文造成障碍
