English：

- Start with pasted reviews

## 模式解释

Product Description Mode：

Best if you know what the product does.

Pasted Reviews Mode：

Best if you have customer complaints, objections, or review snippets.

中文：

产品描述模式：

适合你已经知道产品卖点和痛点。

粘贴评论模式：

适合你有用户评论、差评、购买顾虑或买家原话。
