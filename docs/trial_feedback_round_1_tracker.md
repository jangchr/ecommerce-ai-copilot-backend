## 使用模式选项

- Product Description Mode
- Pasted Reviews Mode
- Both
- Did not try
- Unknown

## 记录重点

- 对方是否愿意打开 demo
- 对方是否知道怎么开始
- 是否成功生成
- 更喜欢产品描述还是粘贴评论
- Hook 是否有用
- Storyboard 是否清楚
- 是否提交 feedback
- 是否加入 waitlist
- 是否要求 Amazon / Shopify / URL input

## 第一轮成功标准

强信号：

- 5 人中至少 2 人成功生成
- 至少 1 人提交有用 feedback
- 至少 1 人愿意继续试用或加入 waitlist

弱信号：

- 有人打开但没有生成
- 有人觉得概念有意思但不清楚怎么用

负信号：

- 多数人不打开
- 多数人看不懂
- 多数人生成后觉得不可用
