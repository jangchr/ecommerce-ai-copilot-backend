# L18 Public Demo Archive

Commit: 4e40ef7

## Archive summary

L18 是 Public Demo UX 重构版本。

目标不是增加后端能力，而是让中文新用户更容易开始试用。

## Key decisions

1. 页面按用户任务组织，而不是按工程模块组织。
2. 三个入口足够覆盖当前试用场景。
3. 结果必须就地展示。
4. 技术概念从主流程移出。
5. 中文模式优先保证朋友试用能看懂。

## Known follow-ups

- 后续可继续优化视觉层级。
- 后续可考虑聊天式需求收集。
- 后续可做真实用户反馈记录。
