# L18 Next Trial Plan

Status: ready

Commit: 24b468f

## 目标

用 L18 final 版本继续收集中文朋友试用反馈。

## 试用对象

优先找：

- 有产品想法但不是电商的人
- 对短视频带货感兴趣的人
- 愿意用中文试一次 demo 的朋友

暂不强求：

- 专业电商卖家
- Shopify / Amazon 用户
- 已经有完整商品库的人

## 建议试用任务

让朋友只做一个任务：

> 选择“我有产品想法”，填一个自己的产品想法，生成一次 TikTok 创意。

如果没有产品想法，则：

> 选择“我先看示例”，先跑一次示例产品。

## 观察问题

记录他们是否卡在：

- 不知道点哪个入口
- 不知道怎么填写产品
- 不理解用户痛点
- 看不懂生成结果
- 找不到复制按钮
- 觉得页面仍然太复杂
- 觉得英文仍然太多
- 想要聊天式引导

## 反馈记录格式

每个人只记录这 5 项：

1. 他/她选择了哪个入口？
2. 有没有成功生成？
3. 卡在哪里？
4. 哪句话/哪个区块看不懂？
5. 他/她觉得这个工具有没有用？

## 决策规则

如果 3 个朋友都能完成一次生成：

- 暂停前端 polish
- 开始考虑下一阶段产品定位 / 试用转化

如果大多数人仍不知道怎么开始：

- 再做 onboarding / flow 改造

如果大家都说想聊天：

- 再评估聊天式需求收集
