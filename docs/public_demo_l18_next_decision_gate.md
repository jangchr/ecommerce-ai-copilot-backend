# L18 Next Decision Gate

Status: ready

Commit: c3050a4

## 目标

避免继续无反馈 polish。

只有满足明确条件，才进入下一轮改动。

## Gate A：继续试用，不改代码

满足任意条件：

- 还没有 3 个真实试用反馈
- 反馈只是“看起来还行”
- 没有明确卡点
- 只是个人觉得还能更好看

动作：

- 不改代码
- 继续找朋友试用
- 记录反馈

## Gate B：小前端修复

满足任意条件：

- 朋友明确指出某个中文文案看不懂
- 某个按钮仍然英文
- 某个输入区明显误导
- 生成后找不到结果
- 移动端某块明显遮挡或裁切

动作：

- 只改 static/index.html
- 更新 tests/test_frontend_probe_boundary.py
- 批量提交
- 集中 Render

## Gate C：重新设计 onboarding

满足任意条件：

- 3 个朋友里至少 2 个不知道从哪里开始
- 多数人不知道“产品想法”该怎么填
- 多数人不理解结果该怎么用

动作：

- 重新设计 onboarding
- 先写文档
- 再改前端

## Gate D：考虑聊天式需求收集

满足任意条件：

- 多数人明确说“想直接聊天说需求”
- 多数人不会写产品描述
- 多数人更愿意回答问题，而不是填表单

动作：

- 先写聊天式 flow spec
- 不直接接 API
- 评估成本和复杂度
- 再决定是否实现

## 当前建议

L18 之后先走 Gate A。

不要继续主动大改。
